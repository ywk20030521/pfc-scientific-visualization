# Observability / cleanup / packaging / findings upgrade (2026-11-24)

Implemented the fused upgrade plan. All new behaviour is opt-in or additive;
the existing data contract and analysis outputs are unchanged.

| PR | Files | Capability |

## Boundaries

- RSS uses `ctypes`/`psapi` on Windows and returns `null` elsewhere; no psutil
  dependency introduced
- Baselines are environment-specific; never compare across hardware
- `display` package contains no raw or scientific delivery data by design
- Feedback loop verifies through `prepare-run` (PROPOSED). Running the new PFC
  task and finalizing to VALIDATED still requires a real Console execution
- No data contract name/version changed; `NOT_CAPTURED` semantics untouched
