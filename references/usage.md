# Usage

## 1. Receive standardized data

Run and validate the experiment with `pfc-headless`. The handoff is one
read-only directory containing:

```text
delivery_manifest.json
experiment.json
cases/case_N/arrays.npz
```

Verify the manifest SHA-256 in the handoff record. Do not pass a raw capture
directory to this Skill.

## 2. Analyze and build

```powershell
& "<python>" "<skill>\scripts\run_pipeline.py" `
  --input "<StandardizedExperiment>" `
  --output "<AnalysisResult>" `
  --title "Experiment Analysis" `
  --max-frames 0
```

Add `--chart-overrides "<overrides>.json"` only when applying a reviewed manual
chart configuration. `--max-frames 0` preserves every real sampled frame in the
Viewer payload; a positive value is explicit Viewer sampling and must be
disclosed.

The pipeline verifies the source contract, then writes only analysis-owned
directories. It does not start PFC, connect to the Bridge, capture data or
standardize arrays.

## 3. Results

- `03_analysis/analysis.json`: derived quantities and statistics.
- `03_analysis/chart_specs.json`: selected chart specifications.
- `03_analysis/chart_decisions.json`: selected and rejected candidates.
- `03_analysis/display_data.json`: formatting and display conversions.
- `03_analysis/data_layers.json`: external standardized parent plus local
  analysis/display lineage.
- `04_viewer/scientific_viewer.html`: offline Viewer shell.
- `04_viewer/viewer/`: local CSS, application and Three.js/ECharts assets.
- `04_viewer/data/`: frame chunks and on-demand Ball histories.
- `04_viewer/linkage_decisions.json`: implemented and omitted linkages.
- `05_charts/chart_specs.json`: publication-chart inventory.
- `07_metadata/source_contract.json`: verified read-only input identity.
- `07_metadata/output_index.json`: actual files and hashes.
- `07_metadata/output_contract.json`: generated, missing, unsupported and
  unverified items.
- `report/experiment_report.md`: analysis summary.

## 4. Viewer interactions

- Switch Cases.
- Drag the real-frame timeline.
- Play/pause/previous/next.
- Locate an exact Cycle; there is no interpolation.
- Track a Ball ID and inspect its real-sample trajectory.
- Switch perspective/orthographic cameras and view presets.
- Toggle particles, Walls, cracks, axes, bounds and trajectory.
- Click temporal charts to return to a frame.
- Drag temporal charts to update the unified frame indicator and 3D state.
- Select one or more 3D Balls and load their histories.
- Brush a current-frame distribution to highlight the matching particle range.
- Export the current scene PNG, chart SVGs and composed PNG panels.

## 5. Rebuild the Viewer

A style or UI change can reuse the existing payload:

```powershell
& "<python>" "<skill>\scripts\build_scientific_viewer.py" `
  --experiment-root "<StandardizedExperiment>" `
  --analysis-root "<AnalysisResult>\03_analysis" `
  --out "<AnalysisResult>\04_viewer\scientific_viewer.html" `
  --max-frames 0
```

Use `--rebuild-payload` only when standardized or analysis arrays changed.

## 6. Verify

```powershell
& "<python>" "<skill>\scripts\verify_payload.py" `
  --experiment-root "<StandardizedExperiment>" `
  --data-root "<AnalysisResult>\04_viewer\data" `
  --report "<AnalysisResult>\07_metadata\payload_integrity.json"

node "<skill>\scripts\verify_lazy_viewer.mjs" `
  --file "<AnalysisResult>\04_viewer\scientific_viewer.html" `
  --report "<AnalysisResult>\07_metadata\browser_acceptance.json" `
  --export-dir "<AnalysisResult>\06_publication_figures\browser_exports"
```

## 7. Publication composition

```powershell
& "<python>" "<skill>\scripts\charts\publication.py" `
  --chart-specs "<AnalysisResult>\03_analysis\chart_specs.json" `
  --svg-dir "<AnalysisResult>\06_publication_figures\browser_exports" `
  --scene-png "<AnalysisResult>\06_publication_figures\browser_exports\viewer_frame.png" `
  --out "<AnalysisResult>\06_publication_figures\figure_1.svg"
```

Missing panels remain absent. PDF output requires a local vector converter.

## 8. Mock contract

`examples/standardized_data/Mock_Experiment` is a read-only contract fixture
generated by `pfc-headless` from the Mock capture. It is marked `MOCK` and is
not evidence of a real experiment.
